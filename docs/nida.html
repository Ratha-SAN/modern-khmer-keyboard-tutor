ក្ដារចុចខ្មែរស្តង់ដារ NiDA

រៀនវាយអក្សរខ្មែរ លើក្ដារចុចដែលមនុស្សគ្រប់គ្នាប្រើ

មេរៀនតាមលំដាប់ពីជួរគោល ដល់ជើងអក្សរ និងល្បែងសម្រាប់ហាត់ ដោយប្រើប្លង់ Khmer Unicode (NiDA) របស់ Windows និង Mac។ ជ្រើសកុំព្យូទ័ររបស់អ្នក រួចចាប់ផ្ដើម។

មេរៀន

មេរៀននីមួយៗណែនាំគ្រាប់ចុចថ្មីៗ ហើយហាត់ជាមួយពាក្យពិត។ ផ្កាយបង្ហាញភាពត្រឹមត្រូវល្អបំផុតរបស់អ្នក។

ល្បែង

ហាត់ល្បឿន និងការចងចាំទីតាំងគ្រាប់ចុច។

បានវាយ

ពណ៌បៃតង = គ្រាប់ចុចគោល (ដាក់ម្រាមដៃនៅទីនេះ)តួអក្សរតូច៖ ខាងលើ = Shift, ខាងក្រោម = AltGr/Option
